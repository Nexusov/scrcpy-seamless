# Security reports

Report suspected security issues privately through the [repository security page](https://github.com/Nexusov/scrcpy-seamless/security).
Use **Report a vulnerability** when private reporting is available. If it is
unavailable, ask the maintainers for a private channel without posting the
details in a public issue.

Include the package version or source commit, the affected platform, the
behavior you observed and the conditions required to see it. Use synthetic
device names and addresses. Omit pairing codes, ADB keys, real configuration,
tokens, personal paths, screenshots and unredacted logs.

This project owns its Desktop application, native fork, Android server changes
and package tooling. For an upstream dependency issue, also follow that
dependency's reporting process. Include the actual shipped library version
when a report concerns a scrcpy Seamless bundle.
